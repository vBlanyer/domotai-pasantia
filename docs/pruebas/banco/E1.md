# E1 · La victima no responde al MDR: escalada a fw-core, aprobada

- nivel: vivo

## Preparar
```bash
docker exec clab-banco-web-banking sh -c 'iptables -I INPUT -s 10.100.0.10 -p tcp --dport 22 -j DROP'
```

## Atacar (desde internet)
```bash
docker exec clab-banco-internet sh -c 'for i in $(seq 1 10); do sshpass -p mal_$i ssh -o StrictHostKeyChecking=no -o ConnectTimeout=4 -o PubkeyAuthentication=no -o PreferredAuthentications=password cliente@10.10.0.10 id >/dev/null 2>&1; done; true'
```

## Esperado
```json
{
 "escalado": true,
 "dispositivo_ejecutor": "fw-core",
 "regla": [
  "fw-core",
  "-A FORWARD -s 198.51.100.10/32 -j DROP"
 ],
 "caen": []
}
```

## Deshacer
```bash
docker exec clab-banco-fw-core iptables -D FORWARD -s 198.51.100.10 -j DROP
docker exec clab-banco-web-banking iptables -D INPUT -s 10.100.0.10 -p tcp --dport 22 -j DROP
docker exec clab-banco-web-banking iptables -D INPUT -s 198.51.100.10 -j DROP
```
